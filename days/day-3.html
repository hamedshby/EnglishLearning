01

واژگان جدید

۸ دقیقه تمرین واژگان مرتبط با پروژه

هر واژه را سه بار با صدای بلند بخوان و سپس آن را در جمله‌ای درباره یکی از پروژه‌های خودت به کار ببر.

02

جملات کاربردی

۷ دقیقه تمرین معرفی پروژه

جمله‌ها را با صدای بلند بخوان و نام پروژه، مسئولیت‌ها و نتایج را با تجربه واقعی خودت جایگزین کن.

I worked on a payment processing project.

من روی یک پروژه پردازش پرداخت کار کردم.

The goal of the project was to improve reliability.

هدف پروژه افزایش قابلیت اطمینان بود.

I was responsible for designing and developing the backend services.

من مسئول طراحی و توسعه سرویس‌های بک‌اند بودم.

One of the main challenges was high API latency.

یکی از چالش‌های اصلی، تأخیر زیاد API بود.

We optimized the database queries and added caching.

ما کوئری‌های پایگاه داده را بهینه کردیم و کش اضافه کردیم.

As a result, we reduced the average response time by 40 percent.

در نتیجه، میانگین زمان پاسخ را ۴۰ درصد کاهش دادیم.

03

نکته گرامری امروز

۵ دقیقه گرامر کاربردی مصاحبه

برای توضیح اقدام‌ها و پروژه‌های تمام‌شده از زمان گذشته ساده استفاده کن.

I designed the service architecture.

من معماری سرویس را طراحی کردم.

We improved the system performance.

ما عملکرد سیستم را بهبود دادیم.

I did not work on the frontend.

من روی فرانت‌اند کار نکردم.

What challenge did you face?

با چه چالشی روبه‌رو شدی؟

فرمول ساده

Negative: Subject + did not + base verb

Question: Did + subject + base verb?

04

سؤال‌های مصاحبه

تمرین پاسخ‌های حرفه‌ای و کوتاه

Interview Question 1

Can you describe a project you are proud of?

I am proud of a payment processing project that I worked on. I designed several backend services and helped improve the reliability of the system.

Interview Question 2

What was the biggest technical challenge in that project?

The biggest challenge was high API latency. We analyzed the slow queries, optimized them and added caching for frequently used data.

Interview Question 3

What was the result of your work?

We reduced the average response time by 40 percent and made the service more reliable during periods of high traffic.

05

تمرین Speaking

معرفی منظم پروژه در پنج مرحله

برای ساختن یک پاسخ کامل، از ترتیب زیر استفاده کن:

Project → Role → Challenge → Action → Result

Project: پروژه چه بود؟

Role: نقش تو چه بود؟

Challenge: چالش اصلی چه بود؟

Action: چه کاری انجام دادی؟

Result: نتیجه قابل‌اندازه‌گیری چه بود؟

I worked on a payment processing project. I was responsible for the backend services. Our main challenge was high API latency. I optimized database queries and added caching. As a result, we reduced the average response time by 40 percent.

06

آزمون کوتاه

مرور واژگان و ساختارهای امروز

Question 1

کدام کلمه به معنی «دستاورد» است؟

A) challenge

B) achievement

C) latency

Answer: B) achievement

Question 2

کدام جمله صحیح است؟

A) We reduce the response time last year.

B) We reduced the response time last year.

Answer: B) We reduced the response time last year.

Question 3

کدام جمله یک نتیجه قابل‌اندازه‌گیری را بیان می‌کند؟

A) The project was interesting.

B) We reduced response time by 40 percent.

Answer: B) We reduced response time by 40 percent.

Question 4

ترتیب مناسب معرفی پروژه کدام است؟

A) Result → Project → Action → Role → Challenge

B) Project → Role → Challenge → Action → Result

Answer: B) Project → Role → Challenge → Action → Result
