01

واژگان جدید

۸ دقیقه یادگیری واژگان فنی

این واژه‌ها برای توضیح مشکل، فرایند بررسی و راه‌حل در مصاحبه کاربرد دارند.

Word معنی Example
bottleneck گلوگاه The database was the main bottleneck.
latency تأخیر API latency increased during peak hours.
root cause علت اصلی We identified the root cause.
investigate بررسی کردن I investigated the application logs.
query کوئری، درخواست پایگاه داده One query was taking too long.
index ایندکس پایگاه داده We added an index to the table.
cache حافظه موقت We cached frequently requested data.
monitor پایش کردن We monitored the service after deployment.
resolve برطرف کردن The changes resolved the timeout issue.
impact اثر، پیامد The issue had a serious impact on users.
02

جملات کاربردی

۶ دقیقه تمرین توضیح چالش

جمله‌ها را به ترتیب بخوان؛ کنار هم یک پاسخ کامل درباره حل مشکل می‌سازند.

We noticed that the API was slow during peak hours.

متوجه شدیم که API در ساعات پرترافیک کند بود.

I was responsible for finding the root cause.

من مسئول پیدا کردن علت اصلی بودم.

First, I checked the logs and performance metrics.

ابتدا لاگ‌ها و معیارهای عملکرد را بررسی کردم.

Then, I found a slow database query.

سپس یک کوئری کند پایگاه داده پیدا کردم.

We added an index and cached frequently requested data.

یک ایندکس اضافه کردیم و داده‌های پرتکرار را کش کردیم.

As a result, latency dropped from two seconds to under 500 milliseconds.

در نتیجه، تأخیر از ۲ ثانیه به کمتر از ۵۰۰ میلی‌ثانیه رسید.

03

نکته گرامری امروز

۵ دقیقه ترتیب و علت‌ومعلول

برای اینکه پاسخ تو منظم و قابل‌دنبال‌کردن باشد، از کلمات ترتیب‌دهنده و عبارت‌های علت‌ومعلول استفاده کن.

First, I reviewed the logs.

ابتدا لاگ‌ها را بررسی کردم.

Then, I reproduced the issue.

سپس مشکل را بازتولید کردم.

Because the query scanned the whole table, it was slow.

چون کوئری کل جدول را پیمایش می‌کرد، کند بود.

We added an index, so the query became faster.

یک ایندکس اضافه کردیم؛ بنابراین کوئری سریع‌تر شد.

As a result, the timeouts stopped.

در نتیجه، خطاهای timeout متوقف شدند.

الگوی پیشنهادی

Sequence: First → Then → After that → Finally

Reason: Because + cause

Effect: So / As a result + result

04

سؤال‌های مصاحبه

پاسخ حرفه‌ای با ساختار STAR

Main Interview Question

Tell me about a technical challenge you faced and how you solved it.

Situation: In one project, our API response time increased to about two seconds during peak hours.

Task: I was responsible for identifying the root cause and improving performance without disrupting users.

Action: First, I reviewed the logs and metrics. Then, I traced the issue to a slow database query. I added an index, introduced caching for frequently requested data and monitored the service after deployment.

Result: We reduced the average latency from ۲ ثانیه to under ۵۰۰ میلی‌ثانیه and eliminated the timeout errors.

Follow-up Question 1

How did you identify the root cause?

I compared the application metrics with database logs and used query analysis to find the operation that scanned the whole table.

Follow-up Question 2

How did you verify that your solution worked?

I ran performance tests before deployment and monitored latency, error rate and database load after the release.

05

تمرین Speaking

ساخت پاسخ در چهار مرحله

هر بخش را در یک یا دو جمله بگو و در پایان آن‌ها را به یک پاسخ ۶۰ تا ۹۰ ثانیه‌ای تبدیل کن.

Situation → Task → Action → Result

Situation: چه مشکلی رخ داد و چه اثری داشت؟

Task: مسئولیت تو چه بود؟

Action: برای پیدا کردن و حل مشکل چه کردی؟

Result: نتیجه را با چه عدد یا نشانه‌ای ثابت کردی؟

Our API became slow during peak hours. I was responsible for finding the root cause. First, I checked the logs and metrics. Then, I found a slow query, added an index and cached frequently used data. As a result, latency dropped below 500 milliseconds and the timeout errors stopped.

06

آزمون کوتاه

مرور واژگان و ساختار STAR

Question 1

کدام عبارت به معنی «علت اصلی» است؟

A) root cause

B) impact

C) cache

Answer: A) root cause

Question 2

در STAR، کدام بخش اقدام‌های تو را توضیح می‌دهد؟

A) Situation

B) Action

C) Result

Answer: B) Action

Question 3

کدام عبارت برای بیان نتیجه مناسب‌تر است؟

A) First

B) Because

C) As a result

Answer: C) As a result

Question 4

کدام نتیجه حرفه‌ای‌تر و قابل‌اندازه‌گیری است؟

A) The API became better.

B) Latency dropped from two seconds to under 500 milliseconds.

Answer: B) Latency dropped from two seconds to under 500 milliseconds.
