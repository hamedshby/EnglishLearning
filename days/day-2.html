02

جملات کاربردی

۷ دقیقه تمرین مکالمه کاری

هر جمله را با صدای بلند بخوان و سپس بدون نگاه‌کردن به متن، آن را با اطلاعات واقعی خودت تکرار کن.

My main responsibility is developing backend services.

مسئولیت اصلی من توسعه سرویس‌های بک‌اند است.

I design REST APIs for different services.

من برای سرویس‌های مختلف REST API طراحی می‌کنم.

I improve application performance.

من عملکرد برنامه را بهبود می‌دهم.

I fix production issues.

من مشکلات محیط عملیاتی را برطرف می‌کنم.

I collaborate with backend developers and QA engineers.

من با برنامه‌نویسان بک‌اند و مهندسان QA همکاری می‌کنم.

I always try to write clean and maintainable code.

همیشه سعی می‌کنم کد تمیز و قابل نگهداری بنویسم.

03

نکته گرامری امروز

۵ دقیقه یادگیری گرامر کاربردی

برای صحبت درباره مسئولیت‌های فعلی از زمان حال ساده استفاده می‌کنیم. برای بیان تجربه‌های گذشته تا امروز از Present Perfect استفاده می‌کنیم.

I develop backend services.

من سرویس‌های بک‌اند توسعه می‌دهم.

I work with SQL Server.

من با SQL Server کار می‌کنم.

I have worked on payment systems.

من روی سیستم‌های پرداخت کار کرده‌ام.

I have developed several microservices.

من چندین میکروسرویس توسعه داده‌ام.

آزمون کوتاه

Question 1

Answer: B) I work with SQL Server.

My main ______ is developing backend services.

Answer: B) responsibility
