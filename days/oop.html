01

Podcast Transcript & Translation

متن پادکست همراه با ترجمه فارسی

Hello.

سلام.

In this episode, we’re going to talk about one of the most important concepts in .NET development: Object-Oriented Programming, or simply OOP.

در این قسمت می‌خواهیم درباره یکی از مهم‌ترین مفاهیم توسعه با دات‌نت صحبت کنیم: برنامه‌نویسی شیءگرا یا به‌اختصار OOP.

If you work with C#, you probably use OOP every day, even if you don’t always notice it.

اگر با C# کار می‌کنید، احتمالاً هر روز از OOP استفاده می‌کنید؛ حتی اگر همیشه متوجه آن نباشید.

So, what exactly is OOP?

پس OOP دقیقاً چیست؟

The main idea behind Object-Oriented Programming is to model software using objects that represent real-world or business concepts.

ایده اصلی برنامه‌نویسی شیءگرا این است که نرم‌افزار را با استفاده از اشیایی مدل‌سازی کنیم که نماینده مفاهیم دنیای واقعی یا کسب‌وکار هستند.

For example, imagine we are building an e-commerce application.

برای مثال، تصور کنید در حال ساخت یک برنامه تجارت الکترونیک هستیم.

We might have concepts such as Customer, Product, Order, and Payment.

ممکن است مفاهیمی مانند مشتری، محصول، سفارش و پرداخت داشته باشیم.

Each of these concepts has some data and some behavior.

هرکدام از این مفاهیم مقداری داده و تعدادی رفتار دارند.

For example, a Product can have information such as a name, price, and stock quantity. It can also have behaviors such as changing the price or reducing the stock.

برای مثال، یک محصول می‌تواند اطلاعاتی مانند نام، قیمت و تعداد موجودی داشته باشد. همچنین می‌تواند رفتارهایی مانند تغییر قیمت یا کاهش موجودی داشته باشد.

In OOP, we usually define these concepts using a class.

در OOP معمولاً این مفاهیم را با استفاده از یک کلاس تعریف می‌کنیم.

You can think of a class as a blueprint or a template.

می‌توانید کلاس را مانند یک نقشه اولیه یا الگو در نظر بگیرید.

For example, we can create a class called Product that describes what information and behavior every product should have.

برای مثال، می‌توانیم کلاسی به نام Product ایجاد کنیم که مشخص می‌کند هر محصول باید چه اطلاعات و رفتارهایی داشته باشد.

But the class itself is not an actual product.

اما خود کلاس یک محصول واقعی نیست.

When we create an instance of that class using the new keyword, we create an object, also called an instance.

وقتی با استفاده از کلمه کلیدی new نمونه‌ای از آن کلاس می‌سازیم، یک شیء ایجاد می‌کنیم که به آن نمونه نیز گفته می‌شود.

var laptop = new Product();

Here, Product is the class, and laptop is an object created from that class.

اینجا Product کلاس است و laptop شیئی است که از آن کلاس ساخته شده است.

One of the main benefits of OOP is that it helps us organize our code in a cleaner and more maintainable way.

یکی از مزایای اصلی OOP این است که کمک می‌کند کد خود را به‌شکلی تمیزتر و نگهداری‌پذیرتر سازمان‌دهی کنیم.

In real-world applications, especially large .NET projects, putting all the business logic into a few large methods or files quickly makes the code difficult to understand, change, and test.

در برنامه‌های واقعی، به‌ویژه پروژه‌های بزرگ دات‌نت، قرار دادن تمام منطق کسب‌وکار در چند متد یا فایل بزرگ خیلی زود فهمیدن، تغییر دادن و آزمایش کد را دشوار می‌کند.

OOP helps us divide responsibilities between different classes.

OOP کمک می‌کند مسئولیت‌ها را میان کلاس‌های مختلف تقسیم کنیم.

There are also four important concepts in Object-Oriented Programming: Encapsulation, Inheritance, Polymorphism, and Abstraction.

در برنامه‌نویسی شیءگرا چهار مفهوم مهم نیز وجود دارد: کپسوله‌سازی، وراثت، چندریختی و انتزاع.

Encapsulation means keeping related data and behavior together and controlling access to internal details.

کپسوله‌سازی یعنی داده‌ها و رفتارهای مرتبط را کنار هم نگه داریم و دسترسی به جزئیات داخلی را کنترل کنیم.

Inheritance allows one class to reuse or extend the behavior of another class.

وراثت به یک کلاس اجازه می‌دهد رفتار کلاس دیگری را دوباره استفاده کند یا گسترش دهد.

Polymorphism means that the same operation can have different implementations depending on the object.

چندریختی یعنی یک عملیات یکسان می‌تواند بسته به شیء، پیاده‌سازی‌های متفاوتی داشته باشد.

And Abstraction means hiding unnecessary implementation details and exposing only what the consumer really needs.

انتزاع نیز یعنی جزئیات غیرضروری پیاده‌سازی را پنهان کنیم و فقط آنچه مصرف‌کننده واقعاً نیاز دارد در اختیارش بگذاریم.

These concepts are not just theoretical ideas.

این مفاهیم فقط ایده‌هایی نظری نیستند.

When you work with ASP.NET Core, Dependency Injection, Entity Framework, Design Patterns, or Software Architecture, you use these OOP concepts all the time.

هنگام کار با ASP.NET Core، تزریق وابستگی، Entity Framework، الگوهای طراحی یا معماری نرم‌افزار همواره از این مفاهیم OOP استفاده می‌کنید.

So, if we want to summarize OOP in one sentence:

پس اگر بخواهیم OOP را در یک جمله خلاصه کنیم:

Object-Oriented Programming is a way of designing software by organizing a system into objects that have their own state and behavior.

برنامه‌نویسی شیءگرا روشی برای طراحی نرم‌افزار است که در آن یک سیستم را به اشیایی با وضعیت و رفتار مخصوص خودشان سازمان‌دهی می‌کنیم.

In the next episodes, we can look more closely at concepts like Class, Object, Property, Field, and Method, and then move on to the four main principles of OOP.

در قسمت‌های بعدی می‌توانیم مفاهیمی مانند کلاس، شیء، ویژگی، فیلد و متد را دقیق‌تر بررسی کنیم و سپس به سراغ چهار اصل اصلی OOP برویم.

If you want to become a strong C# and .NET developer, having a solid understanding of OOP is one of the most important foundations.

اگر می‌خواهید به توسعه‌دهنده‌ای توانمند در C# و دات‌نت تبدیل شوید، داشتن درکی عمیق و محکم از OOP یکی از مهم‌ترین پایه‌هاست.
