Polymorphism

آشنایی با Polymorphism، اجرای رفتارهای متفاوت از طریق یک abstraction مشترک و کاربرد آن در C# و .NET

01

Podcast Transcript & Translation

متن پادکست همراه با ترجمه فارسی

Hello.

سلام.

In this episode, we’re going to talk about one of the most important concepts in Object-Oriented Programming: Polymorphism.

در این قسمت می‌خواهیم درباره یکی از مهم‌ترین مفاهیم برنامه‌نویسی شیءگرا صحبت کنیم: Polymorphism.

The word Polymorphism may sound complicated, but the idea behind it is actually simple.

واژه Polymorphism ممکن است پیچیده به نظر برسد، اما ایده پشت آن در واقع ساده است.

Polymorphism means:

Polymorphism یعنی:

One interface, many behaviors.

یک interface، رفتارهای گوناگون.

In other words, different objects can respond to the same operation in different ways.

به بیان دیگر، objectهای متفاوت می‌توانند به یک operation یکسان، به روش‌های متفاوت پاسخ دهند.

Let’s look at a simple example.

بیایید یک مثال ساده را بررسی کنیم.

Imagine we have an application with different payment methods.

تصور کنید applicationی با روش‌های پرداخت مختلف داریم.

We have credit card payments, PayPal payments, and bank transfer payments.

پرداخت با کارت اعتباری، PayPal و انتقال بانکی داریم.

All of them can make a payment, but each one performs that operation differently.

همه آن‌ها می‌توانند پرداخت انجام دهند، اما هرکدام آن operation را به‌شکل متفاوتی اجرا می‌کنند.

We can start with a base class:

می‌توانیم با یک base class شروع کنیم:

public class Payment
{
    public virtual void Pay()
    {
        Console.WriteLine("Processing payment...");
    }
}

Then we create different payment classes:

سپس classهای مختلف پرداخت را ایجاد می‌کنیم:

public class CreditCardPayment : Payment
{
    public override void Pay()
    {
        Console.WriteLine("Paying by credit card.");
    }
}

And another one:

و یک class دیگر:

public class PayPalPayment : Payment
{
    public override void Pay()
    {
        Console.WriteLine("Paying with PayPal.");
    }
}

Now here is where Polymorphism becomes interesting.

حالا اینجاست که Polymorphism جالب می‌شود.

We can write:

می‌توانیم بنویسیم:

Payment payment = new CreditCardPayment();

payment.Pay();

Even though the variable type is Payment, the object itself is a CreditCardPayment.

با اینکه type متغیر Payment است، خود object از نوع CreditCardPayment است.

So when we call Pay, C# runs the implementation from CreditCardPayment.

بنابراین وقتی Pay را فراخوانی می‌کنیم، C# پیاده‌سازی موجود در CreditCardPayment را اجرا می‌کند.

If we change the object:

اگر object را تغییر دهیم:

Payment payment = new PayPalPayment();

payment.Pay();

The same Pay method now produces different behavior.

همان method با نام Pay اکنون رفتار متفاوتی ایجاد می‌کند.

That is Polymorphism.

این همان Polymorphism است.

The caller does not need to know exactly how each payment method works.

caller لازم نیست دقیقاً بداند هر روش پرداخت چگونه کار می‌کند.

It only knows that every payment can perform a Pay operation.

فقط می‌داند که هر payment می‌تواند operation مربوط به Pay را انجام دهد.

This makes our code much more flexible.

این ویژگی کد ما را بسیار انعطاف‌پذیرتر می‌کند.

For example, imagine we have a list of payments:

برای مثال، تصور کنید فهرستی از paymentها داریم:

List<Payment> payments = new()
{
    new CreditCardPayment(),
    new PayPalPayment()
};

Then we can process all of them using the same code:

سپس می‌توانیم همه آن‌ها را با یک کد یکسان پردازش کنیم:

foreach (var payment in payments)
{
    payment.Pay();
}

Each object automatically executes its own version of the method.

هر object به‌طور خودکار نسخه مخصوص خودش از آن method را اجرا می‌کند.

In C#, runtime Polymorphism is commonly implemented using keywords such as:

در C#، runtime Polymorphism معمولاً با keywordهایی مانند موارد زیر پیاده‌سازی می‌شود:

virtual, override, and abstract.

virtual، override و abstract.

Interfaces are also heavily used for Polymorphism.

interfaceها نیز به‌طور گسترده برای Polymorphism استفاده می‌شوند.

For example:

برای مثال:

public interface IPayment
{
    void Pay();
}

Different classes can implement this interface in completely different ways.

classهای مختلف می‌توانند این interface را به روش‌هایی کاملاً متفاوت پیاده‌سازی کنند.

This approach is extremely common in real .NET applications.

این رویکرد در applicationهای واقعی .NET بسیار رایج است.

You see it in Dependency Injection, repositories, services, logging providers, payment gateways, notification systems, and many design patterns.

آن را در Dependency Injection، repositoryها، serviceها، logging providerها، payment gatewayها، notification systemها و بسیاری از design patternها می‌بینید.

For example, your application might depend on an INotificationService.

برای مثال، application شما ممکن است به یک INotificationService وابسته باشد.

Today, the implementation might send emails.

امروز ممکن است implementation آن ایمیل ارسال کند.

Tomorrow, you could replace it with SMS or push notifications without changing the main business logic.

فردا می‌توانید بدون تغییر منطق اصلی کسب‌وکار، آن را با SMS یا push notification جایگزین کنید.

That is one of the biggest advantages of Polymorphism.

این یکی از بزرگ‌ترین مزایای Polymorphism است.

It allows us to write code that depends on abstractions instead of concrete implementations.

Polymorphism به ما اجازه می‌دهد کدی بنویسیم که به‌جای concrete implementationها به abstractionها وابسته باشد.

As a result, our applications become easier to extend, test, and maintain.

در نتیجه، گسترش، آزمایش و نگهداری applicationهای ما آسان‌تر می‌شود.

So, if we want to summarize Polymorphism in one sentence:

پس اگر بخواهیم Polymorphism را در یک جمله خلاصه کنیم:

Polymorphism allows different objects to be treated through the same abstraction while providing their own behavior.

Polymorphism اجازه می‌دهد objectهای متفاوت از طریق یک abstraction یکسان استفاده شوند و در عین حال رفتار مخصوص خودشان را ارائه دهند.

Instead of writing code that constantly asks:

به‌جای نوشتن کدی که دائماً می‌پرسد:

“Is this a credit card payment?”

«آیا این پرداخت با کارت اعتباری است؟»

“Is this PayPal?”

«آیا این PayPal است؟»

“Is this a bank transfer?”

«آیا این انتقال بانکی است؟»

We simply call:

به‌سادگی فراخوانی می‌کنیم:

Pay.

Pay.

And each object knows what to do.

و هر object می‌داند چه کاری انجام دهد.

That is the real power of Polymorphism in .NET.

این قدرت واقعی Polymorphism در .NET است.
