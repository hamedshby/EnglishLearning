Inheritance in .NET

آشنایی با Inheritance، بازاستفاده و گسترش behavior یک base class و تشخیص رابطه is-a در C# و .NET

01

Podcast Transcript & Translation

متن پادکست همراه با ترجمه فارسی

Hello.

سلام.

In this episode, we’re going to talk about another important principle of Object-Oriented Programming: Inheritance.

در این قسمت می‌خواهیم درباره یکی دیگر از اصول مهم Object-Oriented Programming صحبت کنیم: Inheritance.

Inheritance allows us to create a new class based on an existing class.

Inheritance به ما اجازه می‌دهد بر پایه یک class موجود، class جدیدی بسازیم.

The new class can reuse the fields, properties, and methods of the existing class, and it can also add new behavior or change existing behavior.

class جدید می‌تواند field، property و methodهای class موجود را دوباره به کار بگیرد؛ همچنین می‌تواند behavior جدیدی اضافه کند یا behavior موجود را تغییر دهد.

Let’s look at a simple example.

بیایید یک مثال ساده را بررسی کنیم.

Imagine we are building an application that has different types of employees.

تصور کنید در حال ساخت applicationی هستیم که انواع مختلفی از employee دارد.

We can start with a base class called Employee:

می‌توانیم با یک base class به نام Employee شروع کنیم:

public class Employee
{
    public string Name { get; set; }

    public void Work()
    {
        Console.WriteLine("Employee is working.");
    }
}

Now suppose we have a developer.

حالا فرض کنید یک developer داریم.

A developer is also an employee, so instead of repeating the same properties and methods, we can inherit from the Employee class:

یک developer نیز employee است؛ پس به‌جای تکرار propertyها و methodهای یکسان، می‌توانیم از class Employee ارث‌بری کنیم:

public class Developer : Employee
{
    public string ProgrammingLanguage { get; set; }
}

Now the Developer class automatically has access to the Name property and the Work method.

اکنون class Developer به‌طور خودکار به property Name و method Work دسترسی دارد.

For example:

برای مثال:

var developer = new Developer();

developer.Name = "John";
developer.ProgrammingLanguage = "C#";

developer.Work();

This is one of the main benefits of inheritance: code reuse.

این یکی از مزیت‌های اصلی Inheritance است: code reuse.

We can put common behavior in a base class and reuse it in multiple derived classes.

می‌توانیم behavior مشترک را در یک base class قرار دهیم و آن را در چند derived class دوباره به کار بگیریم.

For example, we might also have:

برای مثال، ممکن است این class را نیز داشته باشیم:

public class Manager : Employee
{
    public int TeamSize { get; set; }
}

Both Developer and Manager inherit the common behavior from Employee.

هر دو class Developer و Manager، behavior مشترک را از Employee به ارث می‌برند.

In inheritance, we usually use two important terms:

در Inheritance معمولاً از دو اصطلاح مهم استفاده می‌کنیم:

The original class is called the base class or parent class.

class اصلی base class یا parent class نامیده می‌شود.

And the class that inherits from it is called the derived class or child class.

و classی که از آن ارث‌بری می‌کند، derived class یا child class نامیده می‌شود.

In C#, inheritance is defined using a colon.

در C#، Inheritance با استفاده از colon تعریف می‌شود.

For example:

برای مثال:

public class Developer : Employee

Another important feature of inheritance is the ability to change behavior in a derived class.

ویژگی مهم دیگر Inheritance، امکان تغییر behavior در یک derived class است.

For example, the base class can define a virtual method:

برای مثال، base class می‌تواند یک method از نوع virtual تعریف کند:

public class Employee
{
    public virtual void Work()
    {
        Console.WriteLine("Employee is working.");
    }
}

Then the derived class can override it:

سپس derived class می‌تواند آن را override کند:

public class Developer : Employee
{
    public override void Work()
    {
        Console.WriteLine("Developer is writing code.");
    }
}

Now the Developer class has its own implementation of the Work method.

اکنون class Developer، implementation خودش از method Work را دارد.

This is also closely related to another OOP principle called Polymorphism.

این ویژگی با اصل دیگری از OOP به نام Polymorphism نیز ارتباط نزدیکی دارد.

However, inheritance should be used carefully.

با این حال، Inheritance باید با دقت استفاده شود.

Just because two classes share some properties does not always mean that one should inherit from the other.

صرفاً اینکه دو class چند property مشترک دارند، همیشه به این معنا نیست که یکی باید از دیگری ارث‌بری کند.

A good inheritance relationship usually represents an is-a relationship.

یک رابطه Inheritance مناسب، معمولاً نشان‌دهنده یک is-a relationship است.

For example: A Developer is an Employee. A Manager is an Employee.

برای مثال: Developer یک Employee است. Manager نیز یک Employee است.

But a Car is not an Engine. A Car has an Engine.

اما Car یک Engine نیست؛ Car یک Engine دارد.

In that case, composition is usually a better choice than inheritance.

در چنین حالتی، Composition معمولاً انتخاب بهتری از Inheritance است.

This distinction is very important in real-world software design.

این تمایز در software design دنیای واقعی بسیار مهم است.

So, if we want to summarize inheritance in one sentence:

پس اگر بخواهیم Inheritance را در یک جمله خلاصه کنیم:

Inheritance allows a class to reuse and extend the behavior of another class.

Inheritance به یک class اجازه می‌دهد behavior یک class دیگر را دوباره به کار بگیرد و گسترش دهد.

In .NET development, inheritance is widely used in frameworks, libraries, domain models, exception classes, ASP.NET Core controllers, and many other areas.

در .NET development، Inheritance در frameworkها، libraryها، domain modelها، exception classها، controllerهای ASP.NET Core و بسیاری حوزه‌های دیگر کاربرد گسترده‌ای دارد.

But good developers do not use inheritance just to avoid duplicate code.

اما developerهای خوب، Inheritance را فقط برای جلوگیری از duplicate code به کار نمی‌برند.

They use it when there is a clear relationship between the base class and the derived class.

آن‌ها زمانی از آن استفاده می‌کنند که میان base class و derived class رابطه‌ای روشن وجود داشته باشد.

Understanding when to use inheritance — and when not to use it — is an important part of writing clean and maintainable object-oriented code.

درک اینکه چه زمانی از Inheritance استفاده کنیم و چه زمانی از آن استفاده نکنیم، بخش مهمی از نوشتن object-oriented code تمیز و قابل‌نگهداری است.
