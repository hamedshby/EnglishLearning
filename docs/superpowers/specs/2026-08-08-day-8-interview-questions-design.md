# طراحی روز هشتم: سه سؤال و پاسخ مصاحبه

## هدف

افزودن روز هشتم دوره با همان سه سؤال و پاسخ انگلیسی ارائه‌شده توسط کاربر، بدون افزودن محتوای آموزشی، پیشنهاد، آزمون، واژگان یا تمرین تکمیلی.

## ساختار صفحه

- یک سربرگ با عنوان «سه سؤال و پاسخ مصاحبه» و نشان «روز هشتم».
- سه بخش شماره‌دار و مجزا.
- هر بخش شامل متن کامل یک سؤال و پاسخ متناظر آن است.
- متن انگلیسی چپ‌چین و با جهت `ltr` نمایش داده می‌شود.
- صفحه از کلاس‌ها و ظاهر موجود پروژه استفاده می‌کند و CSS یا JavaScript عمومی تازه‌ای اضافه نمی‌کند.
- دکمه تکمیل درس در انتهای صفحه حفظ می‌شود.

## محتوا

محتوا دقیقاً شامل این سه موضوع است:

1. معرفی و پیشینه به‌عنوان مهندس نرم‌افزار.
2. پروژه شاخص در Ozone و نقش Senior .NET Backend Developer و Team Lead.
3. چالش درخواست‌های هم‌زمان و راه‌حل‌های rate limiting، Redis distributed locks و optimistic concurrency.

متن سؤال‌ها و پاسخ‌ها بدون بازنویسی محتوایی از درخواست کاربر منتقل می‌شود. فقط قالب‌بندی HTML اعمال خواهد شد.

## یکپارچه‌سازی

- فایل `days/day-8.html` ایجاد می‌شود.
- آیتم روز هشتم با شناسه `8` به منوی «مصاحبه کاری» در `index.html` اضافه می‌شود.
- در روز هفتم دکمه «درس بعدی» به روز هشتم افزوده می‌شود.
- روز هشتم دکمه «درس قبلی» برای بازگشت به روز هفتم خواهد داشت.

## بررسی پذیرش

- روز هشتم از منوی اصلی باز شود و هر سه سؤال و پاسخ کامل را نمایش دهد.
- هیچ بخش آموزشی یا محتوای پیشنهادی دیگری در صفحه وجود نداشته باشد.
- دکمه تکمیل درس و ناوبری میان روزهای هفتم و هشتم با سازوکار فعلی پروژه کار کند.
- آزمون‌های موجود پروژه پس از تغییر همچنان موفق باشند.
