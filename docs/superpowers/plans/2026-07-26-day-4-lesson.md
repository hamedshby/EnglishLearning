### Task 1: Define structural acceptance checks

**Files:**
- Create: `tests/day-4-lesson.ps1`

**Interfaces:**
- Consumes: static files under `index.html` and `days/`
- Produces: an exit-code-based acceptance check for lesson structure, content, navigation, and absent audio references

- [ ] **Step 1: Write the failing test**

Create a PowerShell script that asserts:

```powershell
$day4 = Get-Content -Raw -Encoding UTF8 days/day-4.html
$index = Get-Content -Raw -Encoding UTF8 index.html
$day3 = Get-Content -Raw -Encoding UTF8 days/day-3.html

@(
    '<h1>توضیح یک چالش فنی و نحوه حل آن</h1>',
    'data-lesson="4"',
    'Tell me about a technical challenge you faced and how you solved it.',
    'Situation',
    'Task',
    'Action',
    'Result',
    '۲ ثانیه',
    '۵۰۰ میلی‌ثانیه',
    'checkAnswer(',
    'completeLesson(4)'
) | ForEach-Object {
    if (-not $day4.Contains($_)) { throw "day-4.html is missing: $_" }
}

if ($day4 -match 'day-4.*\.mp3') { throw 'day-4.html references missing audio' }
if (-not $index.Contains('data-day="4"')) { throw 'index.html has no day 4 menu item' }
if (-not $day3.Contains('data-day="4"')) { throw 'day-3.html has no day 4 navigation' }
```

- [ ] **Step 2: Run test to verify it fails**

Run: `pwsh -NoProfile -File tests/day-4-lesson.ps1`

Expected: FAIL because `days/day-4.html` does not exist.

- [ ] **Step 3: Keep the failing check as the contract**

Do not weaken assertions to match implementation. The lesson created in Task 2 must satisfy this contract.
